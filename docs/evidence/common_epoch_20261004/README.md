# 공통 20epoch 실험의 공유용 근거

2026-10-04에 확인한 저장 결과다. 이 폴더는 결과표와 근거를 공유한다. 새 기준으로 다시 채점하거나 새로 학습한 결과가 아니다.

- 같은 학습 사진 2,453장과 검증 사진 107장을 사용했다. 테스트는 97장·정답 박스 225개다.
- 저장본과 탐지 임계값은 검증에서 선택했다. 기존 테스트 열람 이력은 있다.
- 주지표는 IoU 0.5 일대일 대응 F1이다. AP는 프로젝트의 all-points AP이며 COCO AP가 아니다.
- 위치 기준 FN과 사진에 채택 박스가 하나도 없는 경우를 구분한다. 실제 출하 시험이 아니다.
- 실제 정상 제품이 없어 정상 오경보율·현장 재검사량·자동 PASS 안전성은 미검증이다.

| 모델 | 선택 epoch | 검증 F1 | 테스트 F1 | TP/FP/FN | 표시 없는 이물 사진 | MPS 평균 ms/장 |
|---|---:|---:|---:|---|---:|---:|
| YOLOv8n | 20 | 0.9856 | 0.9889 | 222/2/3 | 1 | 11.71 |
| Faster R-CNN | 17 | 0.9918 | 0.9867 | 222/3/3 | 0 | 1396.65 |
| RF-DETR-S | 8 | 0.9918 | 0.9800 | 220/4/5 | 1 | 38.29 |
| D-FINE-S | 11 | 0.9856 | 0.9756 | 220/6/5 | 0 | 24.74 |

## 파일과 한계

- `comparison.csv`: 네 모델의 비교 표. 전체 소수점 값 보존.
- `frozen_selection.json`: 선택 epoch·탐지 임계값·체크포인트 SHA-256과 분할 확인값.
- `training/*/selection.json`: 네 모델 각각의 20epoch 검증 지표와 선택 정책. 과거 세 모델의 이력과 구분.
- `training/*/execution.json`: 실제 학습 설정과 실행 시간. 모델별 장치·batch 등은 동일하지 않다.
- `*_evaluation.json`: 선택 저장본의 검증 및 테스트 채점 결과.
- `diagnostics/`: 조건별 결과, 위치 오류 분석, 실제 사진 검토 기록, 속도와 장치 차이.
- `source_manifest.json`: 로컬 원본과 공유 사본의 해시. JSON 안의 로컬 절대경로만 프로젝트 상대경로로 정규화했다. 숫자와 모델 해시는 보존했다.

속도는 같은 Apple M5 Pro MPS·FP32·batch 1·512 설정에서 검증 107장×3회를 측정했다. 파일 읽기·크기 변환·후처리를 포함하고 색 네모 제거·촬영·설비 동작은 제외한다. 공장 전체 처리량을 측정한 값이 아니다. D-FINE은 CUDA와 MPS 검증에서 경계 점수 한 개의 채택 결과가 달랐다. 탐지 임계값은 보존했다.

원본 사진 전체·공식 TXT 전체·가공 데이터·대용량 가중치는 Git에 없다. 로컬 `runs/`와 승인된 Drive 보관본을 사용한다. 그림과 문서의 원본 근거 경로 중 `data/`, `reports/`, `runs/`는 로컬 전용이다. 이 폴더만으로 새 학습·추론까지 재현한 것은 아니다. 최종 깨끗한 환경 재현 검사는 남아 있다.

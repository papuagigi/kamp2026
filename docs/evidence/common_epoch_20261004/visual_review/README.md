# AI 보조 시각 평가 — 탐색적 결과

Codex가 이 대화에서 실제 확대 그림을 보고 기록한 판정이다. 자동 중심 포함 검사만으로 TP를 만든 결과가 아니다. 그림 생성기는 AI 판정을 생성하지 않으며, 저장 판정의 집계는 기존 `scripts/xray_eval.py`의 `evaluate_visual_review`가 담당한다.

검증 12장·26개 이물의 사전 점검 후 테스트 97장·225개 이물과 네 모델의 채택 예측 899개를 검토했다. 테스트의 모델-이물 패널은 900개다. 두 패널은 예측이 없고, 한 패널은 중복 예측 두 개가 있다. 모델 이름·탐지 점수·IoU는 그림에서 숨겼고 모델 패널 순서를 난수 시드 0으로 섞었다. Codex가 이전 결과를 이미 보았으므로 완전한 독립 블라인드 시험은 아니다.

기준은 **공식 TXT로 식별한 이물의 구분 가능한 검은 중심이 예측 박스 안에 보이고, 박스가 그 위치를 구체적으로 안내하는가**다. 실제 이물의 모든 픽셀 윤곽을 확인하거나 이물의 물리적 성분을 판별한 것은 아니다. 판단 어려움은 별도 기록과 지표 범위로 처리하도록 만들었으며 이번 검토에서 미해결로 남긴 패널은 없다. 미해결 0은 검토자의 오류 0을 증명하지 않는다.

| 모델 | AI 검토 TP | 중복·잘못된 표시 FP | 표시 누락 FN | AI 보조 F1 |
|---|---:|---:|---:|---:|
| YOLOv8n | 224 | 0 | 1 | 0.9978 |
| Faster R-CNN | 225 | 0 | 0 | 1.0000 |
| RF-DETR-S | 224 | 0 | 1 | 0.9978 |
| D-FINE-S | 225 | 1 | 0 | 0.9978 |

## 해석과 한계

- Faster R-CNN은 이 기준에서 225개 모두 표시했다. 공장에서 완벽하다는 뜻은 아니다.
- YOLOv8n과 RF-DETR-S는 서로 다른 사진에서 각각 이물 한 개를 표시하지 않았다.
- D-FINE-S의 FP 1개는 같은 이물에 대한 중복 박스다. 배경을 이물로 판단한 사례와 구분한다.
- 사전 점검 12장은 정상·오류 판정 정답을 독립 전문가가 만든 평가 세트가 아니다. AI 검토자 정확도·검토자 간 일치도는 아직 측정하지 않았다.
- 단일 AI 검토이며 전문가의 독립 확인은 없다. 이번 대화의 검토 모델 정확한 버전·샘플링 설정은 별도로 고정하지 못했다. 기록 집계는 재현할 수 있지만, 새 AI 판단이 항상 같다고 보장하지 않는다.
- 이미 본 테스트의 탐색적 추가 평가다. 기존 IoU 결과, 저장본, 임계값, 공식 TXT는 유지했다. AP는 계산하지 않았다. 임계값 아래 예측은 새로 채택하지 않았다.
- 실제 정상 제품이 없어 정상 오경보율과 특이도, 현장 출하 안전성을 판단할 수 없다. 라벨이 없는 위치의 누락을 전수 판정한 것도 아니다.

## 근거와 재현

`policy.json`은 규칙, `case_manifest.json`은 원본·그림 해시와 모델 매핑, `decisions.json`은 각 패널의 판정과 이유다. `results.json`과 `comparison.csv`는 집계 결과다. `original_iou_regression.json`은 원래 네 모델의 IoU 지표가 바뀌지 않았다는 검사다. 그림 원본은 로컬 `reports/common_epoch_20261004/evaluation/visual_review/`에 있다. 대표 그림은 [표시 누락과 중복](../../../figures/common20_visual_review_examples.png)이다.

로컬 원본·저장 예측이 있는 프로젝트에서 다음 순서로 확인한다.

```sh
.venv/bin/python scripts/xray_visual_review_prepare.py
.venv/bin/python scripts/test_xray_eval.py
.venv/bin/python scripts/test_xray_visual_review.py
.venv/bin/python scripts/xray_visual_review_report.py
```

마지막 명령은 저장된 AI 판정을 검증·집계한다. AI의 시각 검토 자체를 새로 실행하는 명령은 아니다. 판정 기록 없이 자동으로 성공을 채우지 않는다.

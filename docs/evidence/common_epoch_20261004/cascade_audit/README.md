# 단계적 추론과 조건별 전문 모델 검토 근거

2026-10-04. 공식 학습 자료의 조건 분포와 검증 107장·243개 정답 박스만 분석했다. 새 테스트·재학습·새 탐지 임계값 선택은 하지 않았다. 이전 테스트 열람 이력과 검증 반복 사용이 있어 탐색적 개발 결과로 보고한다.

- `policy.json`: 저장 MPS 예측 분석 전에 고정한 규칙·임계값·파일 해시.
- `summary.json`, `pairs.csv`: 네 모델의 위치 기준 성능과 오류 보완 관계.
- `routes.json`, `replay.csv`: 무검출·임계값 근처·표본 추가·전체 추가 검사 규칙. 모델 결과 교체는 비교용이며 실제 안전 판정 규칙이 아니다.
- `conditions.csv`: 학습 자료의 조건별 사진·촬영 묶음 수와 검증 위치 오류. 조건은 정답 위치를 사용한 대리지표이므로 운영 중 놓친 이물을 전달하는 규칙으로 바로 쓸 수 없다.
- `validation_complementarity.csv`: 공식 정답 박스별 검출 여부.
- `illustrated_examples.json`: 그림의 실제 점수·IoU. 세 위치 오류 모두 검은 중심이 표시됨을 단일 AI가 국소 확인했다.
- `consistency_native_csv/`: YOLOv8n 원래 사진·반전 사진을 실제 MPS 추론한 실행 기록, 미리 고정한 정책, 8장 전달 목록과 결과. 이 8장에 기존 RF-DETR-S 예측을 적용한 위치 기준 TP/FP/FN은 241/2/2, F1은 0.9917695473251029다. 원래 사진의 YOLO 결과 240/4/3을 다시 확인했다.
- `manifest.json`: 로컬 원본과 사본의 동일 SHA-256.

초기 반전 exporter의 Python float 변환으로 경계 점수 1개의 채택이 바뀐 `reports/.../cascade_audit/consistency/` 시도는 로컬에 보존했다. 위 결과에는 사용하지 않았다. 기존 공통 CSV와 같은 숫자 저장 형식을 적용했으며 임계값은 바꾸지 않았다.

`oracle_remaining_fn`은 정답을 알고 두 모델의 올바른 결과만 취하는 사후 상한이다. 실제 결합 모델 성능으로 해석하지 않는다. `replacement_*`는 전달된 사진의 결과를 두 번째 모델로 바꾼 대조 분석이다. 첫 모델의 이상 경고를 자동 취소하는 운영 제안이 아니다. 소요 시간 추정은 따로 측정한 사진별 시간을 더한 값이며 실제 연결 시스템 지연이 아니다.

실제 정상 제품·독립 평가자 정확도·공장 지연·PASS 안전성은 미검증이다. IoU 위치 오류 개선을 실제 이물 누락이나 출하 위험 감소라고 부르지 않는다. 최종 설명과 후속 순서는 [모델 정리본 18.13절](../../../20_모델선정과_평가_정리본.md#1813-조건별-전문-모델-연구와-단계적-추론의-첫-실험)에 있다.

재현은 프로젝트 환경과 로컬 데이터·저장본이 필요하다. `scripts/xray_cascade_audit.py` → `scripts/xray_cascade_figure.py` 순서로 CPU 분석을 실행한다. `scripts/xray_cascade_consistency_predict.py`는 MPS 추론을, `scripts/xray_cascade_consistency_audit.py`는 그 결과의 CPU 분석을 수행한다. Git 사본만으로 모델을 새로 학습한 것은 아니다.

## 이번 결론

연구 제안은 **YOLOv8n + Faster R-CNN의 독립적인 전체 추가 검사**다. 검증에서 두 모델의 공통 위치 FN은 0개였고, Faster는 RF-DETR-S와 자체 FP/FN이 같으면서 YOLO의 위치 오류를 더 넓게 보완했다. 정답을 보고 계산한 사후 보완 관계이며 실제 공장 미탐률이나 결합 모델 F1이 아니다. 맥북 MPS 실제 전체 검사 평균 1226.52ms, P95 1253.56ms의 지연과 현장 자원 조건을 함께 제시했다.

최신 YOLO11n·YOLO26n도 같은 학습 조건으로 비교했다. 테스트 F1은 각각 0.9643·0.9733으로 기존 YOLOv8n 0.9889보다 향상되지 않았다. 이 결과를 구조의 보편적 우열로 확대하지 않았다. 첫 경고를 보존하고 충돌·지연·오류를 보류한다. 자동 PASS와 실제 식품 안전성은 검증하지 않았다.

## 확인한 범위

- 표·수치·모델 선정 이유와 한계를 정리 문서와 대조했다. 공식 IoU·AI 시각 검토·제품 처리 상태를 구분했다.
- 보고서 전체 페이지와 발표 슬라이드를 렌더링해 확인했다. 바뀌지 않은 페이지는 이전 확인본과 픽셀을 대조했고, 수정 페이지는 다시 확인했다. PPTX 구조·배치·편집 표·재불러오기 검사를 통과했다. 실제 PowerPoint 앱에서의 최종 렌더는 별도다.
- 편집 파일의 XML과 PDF에서 학교명·개인 이름·홈 경로를 검사했다. 팀명·서명·설문은 빈칸 또는 미완료로 명시했다.
- 재현 ZIP은 CRC와 새 추출 폴더의 **7,233개 파일 해시**, 여섯 모델의 고정 임계값 테스트 재채점을 통과했다. 저장본 여섯 개 로드 및 YOLOv8n·Faster R-CNN의 사진 3장씩 MPS 재추론도 확인했다. 최종 ZIP의 저장본 내부 바이트는 이 추론 검사본과 동일하다.
- 기존 Python 환경에서 확인했다. 새 환경의 전체 재학습이나 전체 테스트의 새 추론을 완료했다고 쓰지 않는다. 개인 경로를 정규화한 내보내기 전후 해시와 텐서 보존 범위는 ZIP의 EXPORT_NOTES.json에 있다.

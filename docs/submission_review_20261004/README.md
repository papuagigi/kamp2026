## 팀이 알아야 할 결론

- 두 모델 모두 같은 전체 사진을 검사한다. RF-DETR-S는 첫 모델의 후보 유무와 관계없이 실행한다.
- 선택 저장본은 YOLOv8n 20epoch, RF-DETR-S 8epoch다. 기존 탐지 임계값 0.68106407과 0.70370466을 유지했다. [고정 정책](../evidence/fullframe_policy_20261005/policy.json)에 경로·해시를 기록했다.
- 검증 107장×3회 실제 전체 사진 실행은 평균36.55ms·P95 44.49ms였다. 촬영·색 네모 제거·설비·대기 시간은 제외했다.
- 기존 테스트 97장을 저장 예측으로 재검증했다. YOLO 무후보 1장과 RF 무후보 1장은 서로 다른 사진이었다. 다른 모델이 각각 경고했다. 두 모델 모두 IoU 기준을 충족하지 못한 이물은 225개 중 2개 남았다.
- 예측이 다르면 두 결과를 보존하고 제품 보류·재검사로 남긴다. 서로 대응해도 정답을 보장하지 않는다. 두 모델 모두 무후보라고 AI만으로 정상 출하를 승인하지 않는다.
- 실제 정상 제품 0장이므로 정상 오경보율·현장 출하 미탐률은 미검증이다. 현재 자료의 모든 사진에 경고가 있었다고 현장 정확도 100%로 쓰지 않는다.

## 재현과 확인 범위

ZIP의 README 순서대로 파일 해시 검사와 여섯 모델 저장 테스트 예측 재채점을 먼저 수행한다. 이어서 `scripts/xray_fullframe_policy.py`로 확정 정책과 사진별 상태를 재생한다. 기존 Python 환경의 저장 결과 재검증이며 새 환경 전체 재학습과 구분한다. 실제 전체 사진 추론은 별도 명령으로 다시 실행할 수 있다.

확인 결과는 `fullframe_review_checks.json`, 산출물 해시는 `manifest.json`에 기록한다. 정책·평가 근거는 [전체 사진 검사 근거](../evidence/fullframe_policy_20261005/audit.json)에 있다. 이전 버전은 이력이며 최신 파일과 혼합해 제출하지 않는다.

## 이번에 보완한 결론

- 합성·의사 라벨의 선행연구는 시험할 이유를 제공한다. 우리 효과의 근거는 자체 비교 결과다. 여덟 조건은 YOLOv8n, batch 8, seed 0, 실제 업데이트 740회의 별도 학습이다. 모든 조건을 20epoch씩 학습한 결과가 아니다.
- 기본 대비 자르기·회전, 합성, 의사 라벨 추가의 검증 F1이 높았다. 이물 전부 제거는 낮았다. 혼합 효과도 단순히 더해지지 않았다. 전체 혼합 2,453장이 최적이라는 증명으로 해석하지 않는다.
- 조건별 FN에 해당 이물 수를 함께 적었다. 조건은 학습 자료에서 정했고 서로 겹칠 수 있다. 모든 모델이 경계 근처에서 더 약하다는 주장은 하지 않는다.
- RF-DETR-S가 보완한 YOLOv8n의 위치 FN은 검증에서 3개 중 2개, 테스트에서 3개 중 1개다. 공통 위치 FN은 각각 1개와 2개 남았다. 이는 IoU 0.5 사후 진단이며 결합 시스템의 F1이나 실제 출하 미탐률이 아니다.
- 두 모델 모두 전체 사진을 검사한다. 같은 학습 자료를 사용하므로 오류가 통계적으로 독립이라고 가정하지 않는다. 충돌·경고는 보존하고 재검사로 연결한다.
- 테스트 97장에서는 두 모델 모두 무후보인 사진이 0장이었다. 실제 정상 제품 0장이고 이전 테스트 확인 이력이 있으므로 현장 정확도 100%로 해석하지 않는다.

## 재현과 기술 확인

ZIP의 README에 따라 `scripts/xray_submission_replay.py`로 파일 해시와 여섯 모델 저장 테스트 예측을 재채점한다. 그다음 `scripts/xray_fullframe_policy.py`로 고정 정책의 검증 107장·테스트 97장 상태를 재생한다. 기존 Python 환경을 사용한 저장 결과 검사이며 새 환경 재학습과 구분한다.

확인 결과는 `editorial_review_checks.json`, 산출물 해시는 `manifest.json`에 기록한다. 데이터·저장본·분할·탐지 임계값을 바꾸지 않았다. 출처 해시는 원래 작업 폴더의 파일을 가리키며, ZIP의 경로 정리된 메타데이터 해시와 다를 수 있다.

공식 여섯 장 구성과 PDF·PPTX·DOCX의 표·그림·한글 배치를 확인했다. **지정 글꼴 휴먼명조는 이 환경에 없어 동일성을 확인하지 못했다. 현재 본문은 AppleMyungjo 14pt, 줄 간격 160%다.** 글꼴까지 제출 형식을 완전히 충족했다고 주장하지 않는다.

사용자 지시에 따라 팀 정보·이름·서명·설문 증빙은 이번 확인 대상에서 제외했다. 기존 표지와 설문 페이지는 변경하지 않았다. 이 버전의 기술 검토는 완료했다. 2026-10-06 사용자 요청에 따라 최신 검토본을 [GitHub main](https://github.com/papuagigi/kamp2026/tree/main)에 공유했다. 포털 제출은 수행하지 않았다.

## 이번에 반영한 내용

| 보고서 위치 | 핵심 내용 |
|---|---|
| 2~10쪽 | EDA → 색 네모 제거 → AI 판독 라벨 → 촬영 묶음 분할 → 증강 12,161장과 검사 결과 |

| 17~19쪽 | 임계값 미달 사진, 조건별 위치 실패, 보완·공통 누락과 실제 사진 |

테스트는 97장·정답 이물 225개다. 2픽셀 위치 F1은 YOLO11s 0.9289, RF-DETR-S 0.9354다. 4·6·8픽셀에서는 각각 1.0000과 0.9978이다. 두 모델의 공통 FN은 2픽셀 9개, 4·6·8픽셀 0개다. 정답을 이용한 보완 표를 운영 조합의 F1로 해석하지 않는다.

이번 평가는 이전 테스트를 확인한 뒤 추가한 **사후 민감도 분석**이다. 기존 선택 저장본·탐지 임계값·평가 TXT·분할을 유지했다. 한 허용 거리를 실제 공장 안전 기준으로 검증한 것은 아니다. 제출 본문은 중심 위치를 다루고, 이전 IoU 결과·원인 분석은 내부 기록으로 보존했다.

## 검사 범위와 남은 일

숫자와 근거 CSV, 표·그림·한글 배치를 확인했다. 새 학습이나 추론 없이 저장 예측을 재채점했다. 처리 시간은 앞서 완료한 MPS 추론 321회의 실측값이다. 현재 성능만으로 전체 재학습을 즉시 시작하지 않는다.

**이전 보고서·발표자료·그 버전의 검사 기록은 현재 GitHub 파일 목록에서 제거했다.** `archive/github_cleanup_20261007/`에 로컬 보관했으며 과거 Git 커밋에서도 복원할 수 있다. 이전 재현 ZIP은 로컬 보관 중이다. 이번 12,161장 학습·위치 평가 보고서와 수치를 혼합하지 않는다. 사용자 검토 후 필요한 내용 수정 → 발표자료와 재현 ZIP 갱신 → 최종 파일 검사 순서가 남았다. 이번 사용자 요청으로 최신 자료를 main에 게시한다. 포털 제출은 별도다.

지정 글꼴 휴먼명조는 현재 환경에 없다. 본문은 기존 AppleMyungjo 14pt·줄 간격 160%를 유지했다. 한글 렌더링은 확인했으나 지정 글꼴까지 일치한다고 주장하지 않는다. 팀 정보·서명·설문 입력란은 보존했다.

이전 32쪽 보고서와 이전 README·manifest는 `reports/center_evaluation_20261007/before/`에 보관했다. 최종 파일 검사 기록은 [공유용 검사 기록](../evidence/center_evaluation_20261007/report_edit_checks.json)과 이 폴더의 `manifest.json`에 있다. 현재 manifest는 남겨 둔 최신 보고서만 가리킨다. 이전 manifest는 로컬 정리 보존본에 있다.

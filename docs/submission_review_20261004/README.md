## 반영한 내용

- EDA를 3쪽·3번 슬라이드에 배치하고, 그다음에 전처리를 설명한다. 중복, 라벨, 작은 박스, 색 네모, 연속 촬영 구조와 전처리 선택을 연결한다.
- 공통 20epoch 학습, 검증에서 선택한 저장본, 네 모델의 테스트 결과를 반영했다.
- 실제 이물이 예측 박스 안에 보여도 IoU 기준에서는 실패로 기록될 수 있다는 사진을 넣었다. 기존 수치는 바꾸지 않았다.
- 위치 기준 FN과 이물 사진에 채택 박스가 하나도 없는 경우를 구분했다. 실제 공장 출하 시험 결과로 표현하지 않는다.
- 실제 정상 제품 부재, 이미 본 테스트, 장치별 수치 차이, 측정 속도의 범위를 명시했다.

## 아직 필요한 일

최종 모델과 운영 임계값 결정, 별도 자료를 이용한 위치 안내 기준과 정상 제품 평가, 제출 묶음의 깨끗한 환경 재현 검사, 팀명·서명·설문 화면 확인이 남아 있다. 보고서의 지정 글꼴인 휴먼명조는 현재 환경에서 확인하지 못해 검토본에는 AppleMyungjo를 사용했다. 제출 전 지정 환경에서 글꼴과 쪽수를 다시 확인해야 한다. 자동 PASS 안전성은 입증되지 않았다.

## 확인 범위

보고서 전체 20쪽과 발표자료 전체 17장의 그림·한글·배치를 확인했다. PPTX의 편집 가능한 표, 파일 구조, 배치 검사와 재불러오기 검사를 통과했다. PDF의 쪽수와 텍스트도 확인했다. 이는 새 학습·추론 또는 최종 환경 재현 검사를 뜻하지 않는다. 파일 해시는 `manifest.json`에 있다.

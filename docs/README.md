라벨링 후보 1,900장 중 명확한 1,876장의 새 학습 라벨을 사용하고 모호한 24장은 제외했다. 라벨 제공 학습 사진 296장과 함께 증강하여 학습 12,161장을 구성했다. 중심 거리 2·4·6·8픽셀로 기존 저장 예측을 재채점하고 실제 오류 위치 40곳을 확인했다. 결과와 한계는 **20번 문서 19.7절**, 새 채점 규칙은 **19번 문서 12.11절**에 있다. 모델·탐지 임계값·평가 TXT는 변경하지 않았다. 현장 PASS 기준은 별도 검증 대상이다.

용어는 **19번 문서의 0절**로 통일한다. 데이터 준비 후 AI 판정과 F1 채점의 쉬운 설명은 **같은 문서의 9절**에 있다. 현재 제출 문서의 위치 채점은 12.11절을 따른다. 보존된 과거 원문은 당시 기록으로 읽는다.

중단 복구와 공통 검증은 **20번 문서 17.9~17.10절**에 있다. MPS와 Colab T4·Drive의 작은 저장·종료·재개 검사를 통과했다. 실제 공장 활용 제안은 **17.11절**에 있다.

[수정 제출 검토본](submission_review_20261004/README.md)은 지표 설명 → 테스트 결과·실패 조건 → 두 모델 보완·공통 누락 → 현장 처리 순서로 개편했다. IoU 수치는 내부 연구 기록에 남겼고 제출 본문에서는 제외했다. 팀 정보·서명·설문은 사용자 요청으로 수정 대상에서 제외했다.

## 이전 자료는 어디에 있나

- [이전 문서 모음](../archive/문서정리_20261002/이전문서모음.md): 기존 설명·계획·회의 자료·작업일지 18개 원문을 한 파일로 모았다. 과거 오류·옛 정책도 이력으로 남아 있으므로 현재 기준으로 바로 사용하지 않는다.

- [기존·신규 설명 그림 목록](figures/README.md): 실행 스크립트가 사용하는 그림 경로를 유지하며 용도를 분류했다.
- `대회자료/`: 원문 PDF·RTF는 원래 위치에 그대로 있다. [대회 규칙 정리본](22_대회규칙과_제출준비.md)에서 각각 열 수 있다.
